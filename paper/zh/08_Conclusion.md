# Conclusion

本文将论文主线明确为 RAIR-RAG：面向灾害受困文本的风险感知意图路由与检索增强生成评测。RAIR-RAG-Bench 提供了一个指南启发、人工复核的合成基准，用于评估高风险路由、否定理解、多意图识别和安全约束。

实验显示，完整的 `risk-router-manual` 在主 test 集上优于关键词 baseline 和关键消融；否定处理显著降低协议误触发，多意图保留提升复杂输入的结构化识别。DE 策略当前没有优于手工策略，应作为校准负结果而非主要性能贡献。

本文同时明确边界：当前不能声称每条样本都有完整权威来源映射，不能把 `reference_reply` 当作已填充字段，也不能把旧 HSC-DisasterBench-v2 / `paper_final_v2` 结果混入 RAIR-RAG 主表。后续工作的重点是补齐样本级证据链、扩展真实噪声覆盖，并在冻结数据划分后继续验证策略校准方法。
