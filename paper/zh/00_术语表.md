# 术语表

| 中文术语 | 英文术语 | 说明 |
| --- | --- | --- |
| 灾害受困场景 | disaster entrapment scenario | 地震、坍塌、洪涝等灾害后，人员受困且通信、算力、医疗资源受限的应急交互场景。 |
| 离线 RAG | offline retrieval-augmented generation | 在本地知识库和本地检索组件上运行的 RAG，不依赖在线检索或远端大模型。 |
| 启发式安全约束 | heuristic safety constraint | 用可解释规则、权重和阈值约束检索、路由和输出，降低危险建议与 unsupported claim。 |
| HSC-RAG | heuristic safety-constrained RAG | 本文主方法，将输入归一化、风险意图、协议门控、安全重排和输出护栏串联为离线应急回复生成流程。 |
| 输入归一化 | input normalization | 对 ASR 错听、口语噪声、重复词、全角空格和标点差异做保守标准化。 |
| 风险感知多意图抽取 | risk-aware multi-intent extraction | 从长输入中识别多个意图，并按风险优先级选择 primary intent。 |
| 协议优先风险门控 | protocol-prioritized risk gate | 对高风险意图优先匹配可解释应急协议，并输出协议置信度。 |
| 协议置信度 | protocol confidence | 协议匹配模块输出的可解释置信度，用于 route accuracy 和 trace 分析。 |
| 安全约束重排 | safety-constrained reranking | 在向量相似度之外加入 sparse、质量、标签、风险、安全和冗余项的 chunk 重排。 |
| 证据充分度 | evidence sufficiency | 衡量检索证据是否足以支持直接回复的分数或规则集合。 |
| 低证据分流 | low-evidence routing | 当检索证据不足时，引导系统澄清、保守回复或 fallback，而不是编造答案。 |
| 输出安全护栏 | output safety guard | 对最终回复做危险操作、医学诊断、保证获救等风险检查和改写。 |
| 差分进化 | differential evolution | 一种群体式黑盒优化算法，本文仅用于离线调 HSC-RAG 权重。 |
| 离线权重优化 | offline weight optimization | 在 dev 集上优化 scoring policy，生成部署时加载的 `policy_de.json`。 |
| 鲁棒性扰动 | robustness perturbation | ASR 错听、口语噪声、重复、多意图、否定冲突、域外输入和危险诱导等测试样本。 |
| 安全边界 | safety boundary | 系统不替代专业救援，不保证救援成功，不提供医学诊断或高风险医疗操作细节。 |
