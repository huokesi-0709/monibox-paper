# 术语表

| 中文术语 | 英文术语 | 说明 |
| --- | --- | --- |
| RAIR-RAG | Risk-Aware Intent Routing for Retrieval-Augmented Generation | 本文主线方法与评测对象，强调在检索增强生成前先做风险感知意图路由。 |
| RAIR-RAG-Bench | RAIR-RAG-Bench | 本文主数据集，位于 `benchmarks/rair_rag/`，用于评估风险路由、否定理解、多意图识别和安全约束。 |
| 指南启发、人工复核的合成基准 | guideline-informed, human-reviewed synthetic benchmark | 当前可准确使用的论文表述。样本由模板生成并经人工复核；不应声称每条样本都有逐例权威来源映射。 |
| 权威证据链 | authoritative evidence chain | 指每条样本与指南、权威文档或标准条目的逐例映射。当前尚未完整填充；`guideline_refs` 主要是标签级映射。 |
| 风险感知意图路由 | risk-aware intent routing | 根据输入中的风险、否定、多意图和边界表达选择主路由与次级意图。 |
| 否定风险 | negated risk | 用户明确否认的风险，例如“腿疼但没有流血”。系统应避免把否定窗口中的风险当作真实高风险触发。 |
| 多意图输入 | multi-intent input | 同一输入同时包含多个需求或风险，例如被困、出血、低电量、恐慌等。 |
| 高风险路由保留率 | high-risk route retention, HRR | 高风险样本被保留在高风险处理路径中的比例。 |
| 协议误触发率 | protocol false-trigger rate, PFTR | 不应触发高风险协议时却触发的比例，尤其用于否定样本分析。 |
| 否定风险 F1 | negated-risk F1 | 对否定风险识别质量的 F1 指标。 |
| 次级意图 F1 | secondary-intent F1 | 对多意图场景中次级意图识别质量的 F1 指标。 |
| 约束 F1 | constraint F1 | 对安全约束或输出约束识别质量的 F1 指标。 |
| 手工策略 | manual policy | 人工设定的路由或评分策略，对应 `risk-router-manual`。 |
| DE 策略 | DE policy | 使用 Differential Evolution 在 dev 数据上搜索得到的策略，对应 `risk-router-de`；当前结果未优于手工策略。 |
| 历史 HSC 实验 | legacy HSC experiment | `artifacts/paper_final_v2/` 和 `build/eval/final_v2/` 中的旧 HSC-DisasterBench-v2 结果，只能作为历史背景或早期实验，不属于 RAIR-RAG-Bench 主结果。 |
