## MoniBox WebUI —— Streamlit 图形化测试前端

### 需求
为纯命令行后端提供轻量美观的图形化测试界面，覆盖 monibox-chat / monibox-rag / monibox-protocol-mock 全部调试场景，支持语音输入和 TTS 播放。

### 已完成

1. **修改 `pyproject.toml`**
   - 新增 `[project.optional-dependencies] webui = ["streamlit>=1.38.0", "scipy>=1.14"]`
   - 新增启动脚本 `monibox-ui = "webui.launch:main"`
   - `hatchling` `only-include` 增加 `"webui"`

2. **新增 `webui/` 目录**
   - `app.py` — Streamlit 主入口，侧边栏（Profile 选择、模型状态、快捷操作、TTS 开关）+ 4 个 Tab
   - `launch.py` — `monibox-ui` 命令包装 `streamlit run`
   - `adapters/web_tts.py` — TTS 适配器，直接复用 sherpa-onnx 底层 API 生成临时 WAV 文件，供 Streamlit `st.audio()` 播放
   - `components/chat_tab.py` — 对话测试（气泡聊天、RAG trace 展开、语音输入 `st.audio_input()`、TTS 播放）
   - `components/rag_tab.py` — RAG 检索调试（查询 + topk/auto_top_tags 参数、结果表格、置信度颜色标记）
   - `components/protocol_tab.py` — 协议测试（查询 + 模拟事件、协议命中/兜底展示、护栏检查日志）
   - `components/status_tab.py` — 系统状态（配置 JSON、模型信息、Trace 日志 tail）

3. **关键技术处理**
   - 模型实例（MoniSession / RagEngine / ProtocolEngine）通过 `st.session_state` 懒加载，避免 Streamlit 重运行导致重复初始化
   - ASR 和 runtime 模块使用函数内延迟导入 + `ImportError` 友好提示，确保 `app.py` 即使缺少可选依赖也能启动
   - TTS 音频数据获取：新增 `WebTTS` 适配器直接调用 `sherpa_onnx.OfflineTts.generate()` 获取 `samples` + `sample_rate`，用 `scipy.io.wavfile` 写临时 WAV

4. **验证结果**
   - `uv sync --extra webui` 安装成功（streamlit 1.58.0 + scipy 1.17.1）
   - `app.py` 静态导入通过 ✅
   - `streamlit run webui/app.py` 启动成功，localhost:8501 可访问 ✅
   - Preview URL 正常打开 ✅

### 启动方式
```bash
uv sync --extra webui                    # 安装依赖
uv run --extra webui streamlit run webui/app.py   # 启动前端
# 或
uv run monibox-ui                        # 通过包装脚本启动
```
